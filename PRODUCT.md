# OpenEval

## Platform
web

## Purpose
OpenEval is a local-first evaluation dashboard for agent CLIs. Observe provides live telemetry, cross-harness transcript collection, and longitudinal analysis. Evaluate provides runs, case/sample comparisons, leaderboard summaries, and evidence audits.

## Confirmed direction
The accepted September 11, 2026 brief requests whole-app visual expansion with progressive depth. Keep initial views calm; reveal detailed controls, comparisons, and source evidence through interaction. Preserve existing routes, factual claims, pricing, parsing, judging, and evaluation semantics. No new judge runs, ingestion sources, or publication are part of this work.

## Evidence
Selections must match the declared population. Loaded rows are not the full corpus. Costs retain recorded/estimated/missing provenance; outcomes retain heuristic/judged/unavailable distinctions. Raw transcripts and filesystem paths do not belong in chart URLs.

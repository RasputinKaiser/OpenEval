## Highest-impact changes

1. Name the product continuously: a compact `OpenEval / Agent Evaluation` strap from 0–26 seconds.
2. Make the actual app readable: lift brightness/contrast on every authentic product clip and add a focal edge to the primary surface in each feature scene.
3. Clean the hook handoff: reduce the TouchDesigner scan dominance and remove the crushed, empty-looking proof bars during “now make it evidence.”
4. Clarify the final proof beat: add `cost. performance. accuracy.` above the bench/audit surfaces before the OpenEval close.

# Real application screenshots

These two images were supplied by the project maintainer on September 12, 2026 and show a real local OpenEval installation. They are published with text and EXIF metadata removed; their image pixels are unchanged, not generated or reconstructed. Capture-time layout and totals may differ from the latest application.

- `collection-overview.png`: aggregate inventory, estimated API cost, tool activity, and evidence coverage.
- `model-analytics.png`: model-level usage, error rates, and API-equivalent estimates.

Both images were visually reviewed before publication. No visible conversation text, private project names, local paths, credentials, or personal identities were found. PNG text and EXIF metadata were removed before publishing. Other captures containing private session titles and project details were excluded.

The numeric values are personal installation snapshots, not benchmark results. Estimated API-equivalent costs do not represent actual payments or subscription usage. Only these two explicitly allowlisted images are copied into the public website.

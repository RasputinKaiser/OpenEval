# Calibration contract chosen by PM

References are append-only versions with author label, created time, outcome, rationale, cited IDs, and exact source/session/packet digest/version/rubric. Creating a new version retains old versions. An explicit user authoring action attests human authorship; imported records carry declared/imported provenance and cannot masquerade as newly authored. Synthetic fixtures never enter the human-reference denominator.

Evaluation observations are imported structured records, or existing receipts if the implementation can bind all required fields honestly. Preserve backend/model/effort/prompt, exact identity and digest, nullable cost and elapsed time. Do not invoke providers. Reject invalid enum, numbers, duplicate record IDs with differing payloads, oversized batches, absent identity and malformed JSON. Additive persistence must be atomic for imports. Repeating an identical import should not inflate counts.

Compare exact rubric/evidence matches only. Group results by review method rather than pool methods. Denominators must be explicit: agreement over matched judgments; false-success rate over achieved predictions with known non-insufficient references; abstention rate over all matched judgments; citation validity over supplied citation IDs present in the matching evidence inventory. Missing evidence inventory means citation validity unknown, not valid. Repeated outcomes within the same method/reference define stability; a single judgment has no repeatability measurement. Cost/time aggregates count available values and preserve missing values. No ground-truth claim beyond reviewed references; uncertainty and disagreement visible.

The UI needs a usable reference form, reference/version list, structured observation import with example format, and per-method reports. Human reference authoring must be possible without manually assembling a complete JSON packet. Form may accept exact identity/digest/rubric and cited IDs initially, with an inspect-source link. Empty states explain what to add. Final browser tests author synthetic-labeled test data only in an isolated data root.

Accuracy layout integration: retain existing structural audit. Add a clearly titled calibration section accessible near the page top with progressive disclosure, so users can find reference authoring without scrolling through the entire case matrix. Do not mix structural-case counts with calibration-session denominators.

Reference form provenance must include a synthetic/test option so UI validation can exercise authoring honestly in an isolated data root. Manual-reference creation requires an explicit human-review attestation; automated UI validation must not check that attestation for real data. Synthetic references can be evaluated in a clearly labeled fixture report but never pooled into human calibration.

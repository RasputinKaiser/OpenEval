# Watchable evaluations

Three new public visual-code cases: Kinetic Marble Lab, Firefly Garden, Pocket Rhythm. Each requests a self-contained interactive canvas artifact with keyboard/touch controls, pause/reset, tempo, visible state, and reduced-motion startup behavior. A deterministic state interface enables bounded VM checks for particle count, time advance, movement, interaction and reset; known-bad static placeholders must fail. These checks are not rendered-quality or full physics/rhythm correctness certification.

Reference solutions appear at `/cases/playground`, explicitly labeled as references, not agent outputs or benchmark scores. Case library links to the playground; individual challenge links and the Watchable playground New Run preset configure evaluation without starting it.

Shared artifact previews add Play/Stop, Replay and Tall view. Static preview is the default. Playback runs inline scripts in a sandbox with no same-origin, parent navigation, popups or forms permissions. A prepended CSP blocks network subresources, nested frames, objects and form submissions; external dependencies are unsupported. The preview is an interactive artifact viewer, not an evaluation verdict. Stop/Replay remount and reset the document; use an artifact's own Pause control to preserve simulation state.

Expanded running/pending case previews poll for artifact bytes every four seconds after each request completes; unchanged srcDoc content is retained. Terminal/collapsed stages stop polling. This observes saved file revisions, not a video stream of the agent's desktop, and a changed document restarts its animation.
